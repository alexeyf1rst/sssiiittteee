# Тёплый контур — кухни, Минск

Презентационный сайт для ремонта и отделки кухонь. Рабочий бренд «Тёплый контур».

## Возможности

- Адаптивный дизайн, мобильное меню, FAQ и окно информации о проекте.
- Подбор палитры материалов.
- Сбор задания на ремонт и скачивание TXT-файла с выбранными параметрами.
- SEO-описание и Open Graph для превью ссылки.
- Статические HTML, CSS и JavaScript. Сборка и npm не нужны.

## Запуск

Откройте index.html или запустите `python3 -m http.server 8080` из папки сайта.

## Перед запуском рекламы

Замените рабочее название и добавьте проверенный контакт компании. Сейчас форма сохраняет задание на устройство, а не отправляет заявку. При подключении сервера для заявок необходимо реализовать обработку ошибок, защиту от спама и согласовать текст обработки данных с владельцем бизнеса.

Уточните с компанией перечень услуг. Цены, сроки, гарантии и отзывы намеренно не выдуманы. Изображение является AI-концепцией, это обозначено на странице; замените его реальным портфолио при наличии.

## Изображение

`assets/kitchen.jpg` создано встроенным imagegen. Запрос: фотореалистичная интерьерная фотография современной кухни в Минске, натуральный дуб, светлый известняк, оливковые шкафы, тёплый дневной свет, композиция 16:9, без людей, текста и логотипов. Оптимизировано в JPEG.

Шрифты Manrope и Prata загружаются через Google Fonts; предусмотрены системные альтернативы.
