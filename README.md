# Форма — лендинг

Адаптивный шаблон лендинга digital-студии на русском языке.

## Просмотр

Откройте `index.html` в браузере. Установка и сборка не нужны.

## Состав

- HTML, CSS и JavaScript в одном файле.
- Адаптивная верстка для мобильных и настольных экранов.
- Демо-форма заявки: данные не отправляются и не сохраняются.

## Публикация

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.
